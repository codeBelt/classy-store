## subscribeKey

Subscribe to changes on a single property. Other property changes don't trigger the callback.

**API** · `subscribeKey(store, key, callback, options?): () => void` from `@codebelt/classy-store/utils`.

The subscription compares each property using `Object.is`. Updating the other property leaves its log alone.
